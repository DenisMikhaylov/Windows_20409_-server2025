Конечно. Вот подробное продолжение лабораторной работы по развертыванию System Center Virtual Machine Manager (SCVMM) 2025 с использованием выделенных серверов для управления и базы данных. Мы создадим две новые виртуальные машины на основе разностных дисков и выполним все необходимые шаги для установки и настройки.

---

## Лабораторная работа: Развертывание System Center Virtual Machine Manager 2025

**Цель работы:** Развернуть инфраструктуру управления виртуализацией, состоящую из сервера SCVMM 2025 и выделенного SQL Server для его базы данных. Полученный инструмент будет использоваться для централизованного управления кластером Hyper-V, созданным в предыдущей лабораторной работе.

**Архитектура:**
*   **LON-VMM1:** Сервер управления VMM.
*   **LON-SQL1:** Сервер баз данных для VMM.
*   **Базовая инфраструктура:** Используются разностные диски на основе родительского диска `base2025.vhdx`.
*   **Сеть:** Внутренняя сеть с фиксированными IP-адресами (см. таблицу).

| Виртуальная машина | IP-адрес | Назначение |
| :--- | :--- | :--- |
| LON-HOST1 | 192.168.10.1 | Узел кластера Hyper-V |
| LON-HOST2 | 192.168.10.2 | Узел кластера Hyper-V |
| LON-SS1 | 192.168.10.3 | Сервер iSCSI-хранилища |
| **LON-VMM1** | 192.168.10.4 | **Сервер управления VMM** |
| **LON-SQL1** | 192.168.10.5 | **Сервер SQL Server** |

---

### Часть 1: Создание и подготовка виртуальных машин LON-SQL1 и LON-VMM1

**1.1. Создание разностных дисков**

Как и в предыдущей работе, для экономии места создадим разностные диски для новых машин на основе `base2025.vhdx`:

```powershell
# На физическом хосте Hyper-V
# Создаем разностный диск для LON-VMM1
New-VHD -Path "C:\VHDs\LON-VMM1.vhdx" -ParentPath "C:\VHDs\base2025.vhdx" -Differencing

# Создаем разностный диск для LON-SQL1
New-VHD -Path "C:\VHDs\LON-SQL1.vhdx" -ParentPath "C:\VHDs\base2025.vhdx" -Differencing
```

**1.2. Создание и настройка виртуальных машин**

Создайте виртуальные машины с параметрами, соответствующими их ролям . Для сервера VMM рекомендуется выделить больше ресурсов.

```powershell
# Создание LON-VMM1 (рекомендуется 16+ ГБ ОЗУ, 4+ vCPU)
New-VM -Name "LON-VMM1" -MemoryStartupBytes 16GB -BootDevice VHD -VHDPath "C:\VHDs\LON-VMM1.vhdx" -Path "C:\Hyper-V" -Generation 2 -SwitchName "Внешняя сеть"
Set-VMProcessor -VMName "LON-VMM1" -Count 4

# Создание LON-SQL1 (рекомендуется 16+ ГБ ОЗУ, 4+ vCPU)
New-VM -Name "LON-SQL1" -MemoryStartupBytes 16GB -BootDevice VHD -VHDPath "C:\VHDs\LON-SQL1.vhdx" -Path "C:\Hyper-V" -Generation 2 -SwitchName "Внешняя сеть"
Set-VMProcessor -VMName "LON-SQL1" -Count 4

# Добавляем дополнительный диск для базы данных VMM на LON-SQL1
New-VHD -Path "C:\VHDs\LON-SQL1-Data.vhdx" -SizeBytes 100GB -Dynamic
Add-VMHardDiskDrive -VMName "LON-SQL1" -Path "C:\VHDs\LON-SQL1-Data.vhdx"
```

**1.3. Первоначальная настройка гостевых ОС**

Запустите виртуальные машины и выполните следующие шаги:

1.  **Настройка сети:** Присвойте статические IP-адреса (`192.168.10.4` для LON-VMM1, `192.168.10.5` для LON-SQL1).
2.  **Имена компьютеров:** Переименуйте серверы и перезагрузите их.
3.  **Вступление в домен:** Вступите обе машины в ваш домен (предполагается, что он есть в инфраструктуре, как указано в руководствах по установке VMM) . Используйте учетную запись, имеющую права на вступление в домен.
4.  **Служебная учетная запись:** Рекомендуется создать в Active Directory отдельную учетную запись для службы VMM (например, `svc_vmm`) и для службы SQL Server (например, `svc_sql`). Эти учетные записи должны быть администраторами на соответствующих серверах .

### Часть 2: Установка и настройка SQL Server на LON-SQL1

SCVMM требует базу данных SQL Server, и для корректной работы необходимо установить совместимую версию . В зависимости от предоставленных ISO-образов, выберите поддерживаемую версию (SQL Server 2022 или 2019). В данном примере рассмотрим установку SQL Server 2022.

**2.1. Установка SQL Server 2022 Database Engine**

1.  На `LON-SQL1` подключите ISO-образ SQL Server 2022 и запустите `setup.exe` .
2.  В **SQL Server Installation Center** выберите **"New SQL Server stand-alone installation..."** .
3.  Пройдите этапы проверки лицензии и правил.
4.  На вкладке **Feature Selection** отметьте **"Database Engine Services"** (Службы ядра СУБД) и **"SQL Server Management Studio (SSMS)"** (или установите его отдельно позже) .
5.  В **Instance Configuration** оставьте экземпляр по умолчанию (`MSSQLSERVER`) или укажите имя.
6.  В **Server Configuration** укажите **"Service Account"** для SQL Server (рекомендуется использовать специальную учетную запись службы, например, `svc_sql`).
7.  В **Database Engine Configuration** перейдите на вкладку **"Authentication"**, выберите смешанный режим ("Mixed Mode") и задайте пароль для пользователя `sa`. Затем на вкладке **"Specify SQL Server administrators"** нажмите **"Add Current User"**, чтобы добавить себя как администратора. Также можно добавить учетную запись службы VMM (`svc_vmm`) .
8.  На вкладке **Data Directories** укажите пути для хранения файлов базы данных на дополнительном диске (`E:\Data`, `E:\Logs` и т.д.).
9.  Завершите установку и установите последние обновления при необходимости.

**2.2. Настройка командной строки SQL (Важно!)**

VMM требует установки командной утилиты SQL Server, соответствующей вашей версии . Это не выполняется автоматически при установке ядра СУБД.

1.  Найдите в дистрибутиве SQL Server установщик `SqlCmdLnUtils.msi` (или скачайте его из Feature Pack) и установите.

**2.3. Настройка брандмауэра**

Убедитесь, что порт 1433 (по умолчанию) открыт на брандмауэре LON-SQL1, чтобы сервер VMM мог подключиться к базе данных .

### Часть 3: Установка и настройка SCVMM 2025 на LON-VMM1

Перед установкой VMM необходимо подготовить операционную систему, установив обязательные компоненты .

**3.1. Установка предварительных требований**

1.  **Windows ADK (Assessment and Deployment Kit):** Установите Windows ADK для Windows 11, версия 24H2. Во время установки обязательно выберите **"Deployment Tools"** и **"Windows Preinstallation Environment (Windows PE)"** .
    *   *Примечание:* Иногда возникает ошибка с путями к файлам ADK. Если это произошло, скопируйте файлы из папки `C:\Program Files (x86)\Windows Kits\10\Assessment and Deployment Kit\Deployment Tools\WSIM\amd64` в `C:\Program Files (x86)\Windows Kits\10\Assessment and Deployment Kit\Deployment Tools\WSIM` .
2.  **Командные утилиты SQL:** Установите `SqlCmdLnUtils.msi`, если вы не сделали этого на LON-SQL1. Версия должна соответствовать вашей SQL Server .

**3.2. Запуск установки VMM**

1.  На `LON-VMM1` подключите ISO-образ SCVMM 2025 и запустите `setup.exe` от имени администратора.
2.  На главной странице выберите **"Install"** .
3.  В разделе **"Select features to install"** отметьте **"VMM management server"** (консоль установится автоматически) .
4.  Укажите путь для установки (по умолчанию: `C:\Program Files\Microsoft System Center 2025\Virtual Machine Manager`).
5.  На странице **Database Configuration** укажите:
    *   **Server name:** `LON-SQL1` (или его FQDN) .
    *   **Instance name:** Имя экземпляра SQL (например, `MSSQLSERVER` или оставьте пустым для стандартного).
    *   Выберите **"Create a new database"** и дайте ей имя (по умолчанию `VirtualManagerDB`).
    *   Выберите **"Use the following credentials"** и введите учетные данные администратора SQL Server (например, `sa`), чтобы установщик мог создать базу данных . *Примечание: Учетная запись, используемая для установки, должна иметь роль sysadmin на SQL Server .*
6.  На странице **Service account and distributed key management** укажите учетную запись службы VMM (`svc_vmm`) и введите пароль. Рекомендуется не хранить ключи в Active Directory на этом этапе .
7.  На странице **Port configuration** оставьте порты по умолчанию.
8.  На странице **Library configuration** оставьте путь к библиотеке по умолчанию (можно изменить позже).
9.  Завершите установку, дождавшись ее окончания. После успешной установки можно открыть консоль VMM.

### Часть 4: Добавление кластера Hyper-V в управление SCVMM

Теперь вы можете использовать SCVMM для управления вашим кластером Hyper-V, созданным в прошлой лабораторной работе .

1.  Откройте консоль VMM.
2.  Перейдите в **Fabric -> Servers -> All Hosts**.
3.  Нажмите **"Add Resources"** -> **"Hyper-V Hosts and Clusters"** в верхней панели.
4.  В мастере выберите **"Windows Server computers in an Active Directory domain"** и укажите учетную запись, имеющую права администратора на всех узлах кластера.
5.  На следующем шаге нажмите **"Browse"**, выберите ваш кластер `HyperVCluster` из списка AD и добавьте его.
6.  Пройдите оставшиеся шаги мастера, принимая настройки по умолчанию, чтобы добавить кластер в SCVMM.


Теперь у вас есть полноценное решение для управления виртуальной инфраструктурой на базе System Center 2025.
